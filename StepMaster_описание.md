# StepMaster — полное описание программы

## Что это

StepMaster — программа для Windows 10 и 11, которая собирает в одном окне главные инструменты обслуживания компьютера: очистку мусора, анализ диска, управление программами, автозагрузкой, процессами и службами, защиту, сеть и ускорение для игр. Многое из этого в самой Windows разбросано по панели управления, «Параметрам», «Диспетчеру задач» и консольным командам, а часть функций в Windows вообще нет.

- **Для кого:** для себя и друзей. Программа бесплатная, не продаётся.
- **Формат:** один файл `StepMaster.exe` (~14 МБ). Он же и установщик, и сама программа.
- **Установка:** при первом запуске открывается небольшое окно «Установка StepMaster» в стиле программы.
  - Папка по умолчанию — `C:\Program Files\StepMaster`, кнопка «Изменить» выбирает другую. Программа всегда ставится в свою папку `StepMaster` внутри выбранной, чтобы не смешаться с чужими файлами.
  - Галочки «Ярлык на рабочем столе» и «Ярлык в меню «Пуск»» (обе включены).
  - «Установить» копирует программу, добавляет её в список приложений Windows («Параметры → Приложения», разработчик — Cinailo Corp.), создаёт ярлыки и сразу запускает установленную копию. Шаги видны по ходу.
  - Нельзя ставить в корень диска, в папку Windows и в системные папки.
  - Установка обязательна: запустить программу, не установив её, нельзя.
  - Если StepMaster уже установлен, папка подставляется прежняя; установка заменит его, настройки сохранятся. Запущенная установленная копия закрывается сама.
  - Без прав администратора кнопка «Установить» сама запрашивает их у Windows (UAC).
- **Удаление:** как у любой программы — «Параметры → Приложения → StepMaster → Удалить». Открывается окно «Удалить StepMaster?» с галочкой «Удалить также настройки и историю очистки». Удаляются программа, ярлыки, задание автозапуска и запись в списке приложений.
- **Права:** при запуске Windows спрашивает права администратора (UAC). Они нужны для очистки системных папок, служб, брандмауэра, DNS и т. п. Без прав программа тоже открывается: показывает плашку «запущена без прав администратора», а действия, которым нужны права, становятся неактивными.
- **Системы:** Windows 10 и Windows 11. Нужен компонент WebView2 — на Windows 11 и обновлённой Windows 10 он уже есть.
- **Язык:** русский по умолчанию, английский переключается в настройках.
- **Текущая версия:** 1.0.5.
- **Исходный код и загрузка:** https://github.com/c1naii/StepMaster, готовый файл — в разделе Releases.

## Внешний вид и управление

- **Дизайн:** тёмный монохромный, почти чёрный фон, светлый текст, белый акцент, тонкие рамки, скругления, много воздуха. Стиль близок к Linear, Raycast и Vercel. Шрифт Manrope.
- **Окно:** без стандартной рамки Windows. Собственная шапка с поиском и кнопками «Свернуть», «Развернуть», «Закрыть». Окно можно таскать за шапку и растягивать, минимальный размер 1080×700.
- **Боковое меню:** слева, 10 разделов — Главная, Диагностика, Очистка, Диск, Программы, Система, Защита, Сеть, Игры, Настройки.
- **«Жидкое стекло».** Подсветка выбранного пункта в боковом меню и во всех вкладках-переключателях — это одна «живая» линза.
  - Обычный клик: подсветка плавно переезжает к пункту.
  - Если зажать левую кнопку мыши на пункте и вести вверх-вниз (во вкладках — влево-вправо), подсветка приподнимается стеклянной линзой: полупрозрачная, с бликом, тенью и размытием.
  - Линза едет за курсором с пружинной инерцией, слегка растягивается от скорости, а у краёв мягко «пружинит».
  - Во вкладках линза ещё меняет ширину под вкладку, над которой находится.
  - Отпустил кнопку — открывается пункт под линзой. Долгое удержание без движения тоже поднимает линзу.
- **Анимации:**
  - плавные переходы между разделами;
  - каскадное появление карточек;
  - отсчёт чисел на главной;
  - анимированное кольцо очистки;
  - кнопки слегка «вжимаются» при нажатии.
  В настройках анимации можно уменьшить или выключить. Системная настройка «уменьшить движение» тоже учитывается.
- **Поиск и действия (`Ctrl+K`).** Палитра команд: набираешь, например, «очист», и стрелками с Enter переходишь в раздел или сразу выполняешь действие. Там есть:
  - умная диагностика ПК;
  - разбор загрузок;
  - быстрая очистка;
  - сброс DNS;
  - проверка антивирусом;
  - точка восстановления;
  - игровой режим;
  - тест скорости;
  - большие файлы;
  - автозагрузка, процессы и службы;
  - пароли Wi-Fi;
  - Диспетчер задач и Центр обновлений Windows.
- **Глобальная горячая клавиша:** по умолчанию `Ctrl+Shift+Space`. Открывает StepMaster с палитрой из любой программы.
- **Значок в трее:**
  - левый клик открывает окно;
  - меню: «Открыть StepMaster» и «Выход»;
  - подсказка у значка показывает загрузку процессора и памяти, обновляется каждые 3 секунды.
- **Закрытие окна** по умолчанию прячет программу в трей, а не выключает её (меняется в настройках).
- **Один экземпляр:** повторный запуск не открывает вторую копию, а показывает уже открытое окно.
- **Подтверждения:** все опасные действия (удаление, выключение брандмауэра, сброс сети, завершение процесса) спрашивают подтверждение. Фокус стоит на «Отмена», поэтому случайный Enter ничего не удалит. Окна закрываются по Escape.
- **Уведомления:** результаты действий появляются в правом нижнем углу.

## Разделы и функции

### 1. Главная

Сводка состояния компьютера:

- **Приветствие** по времени суток с именем пользователя Windows и строка состояния: «Можно освободить N ГБ» или «Всё в порядке».
- **Большая карточка системного диска.** Процент заполнения крупными цифрами, «X из Y занято», полоса заполнения и кнопка «Очистить». Если диск заполнен на 85% и больше, заголовок меняется на «Диск C почти заполнен».
- **Четыре карточки.** Диск, Память, Процессор (загрузка и частота) и Защита (работает ли антивирус, ссылка «Открыть Безопасность Windows»). У диска, памяти и процессора есть мини-графики, они обновляются каждые 2 секунды.
- **Быстрые действия:** Очистка, Автозагрузка, Проверка (быстрая проверка антивирусом), Сброс DNS.
- **Советы с кнопкой «Исправить».** Появляются, только когда есть повод:
  - в автозагрузке 8 программ и больше;
  - выключена защита в реальном времени;
  - базы антивируса старше 7 дней;
  - брандмауэр выключен для части сетей;
  - память занята на 90% и больше.
- **Совет про диагностику:** если умную диагностику ещё не запускали или запускали больше 14 дней назад, появляется совет её пройти. Если в последнем отчёте есть серьёзные проблемы, совет показывает оценку и число проблем.
- **Счётчик:** сколько всего места освобождено очистками за всё время.

### 2. Диагностика (умная диагностика ПК)

Комплексная автоматическая проверка компьютера на проблемы. Запускается одной кнопкой «Начать диагностику».

- **Проверка на вирусы.** Переключатель «Проверить на вирусы» (включён по умолчанию): перед анализом запускается быстрая проверка Microsoft Defender, это добавляет 2–10 минут. Без неё диагностика занимает около 15–30 секунд.
- **Ход проверки:** кольцо с процентами и список шагов — проверка на вирусы, журналы Windows и оборудование, производительность и признаки заражения, анализ результатов.
- **Что проверяется** (около 35 проверок в 5 группах):
  - **Производительность:** загрузка процессора (средняя за несколько секунд, с самыми прожорливыми программами), занятость памяти (с самыми тяжёлыми программами), место на системном диске, объём мусора и кэша, число программ в автозагрузке, план питания «Экономия энергии» на настольном ПК, время без перезагрузки, ожидающая перезагрузка Windows.
  - **Перегрев и питание:** температура процессора (если есть датчик), температура видеокарты NVIDIA, замедление процессора прошивкой за неделю (признак перегрева или нехватки питания), износ батареи ноутбука.
  - **Оборудование:** здоровье дисков (статус, износ SSD, ошибки чтения, предупреждения SMART), устройства с ошибками и без драйверов, аппаратные ошибки WHEA (процессор, память, PCIe).
  - **Ошибки и сбои Windows:** синие экраны за месяц, внезапные выключения, ошибки диска и файловой системы, вылеты программ за неделю (с названиями), ошибки установки обновлений, отключённая служба обновлений, выключенный контроль учётных записей (UAC).
  - **Безопасность:**
    - активные угрозы Microsoft Defender;
    - выключенная защита в реальном времени (если нет другого антивируса);
    - устаревшие базы, давняя проверка на вирусы, выключенный брандмауэр;
    - исключения антивируса;
    - признаки вредоносного ПО: подозрительная автозагрузка (запуск из временных папок, «Загрузок», общей папки, скрытый PowerShell, ссылки на несуществующие файлы), неподписанные процессы из временных папок и «Загрузок», подозрительные задачи в планировщике, записи в файле hosts, перенаправляющие антивирусные или популярные сайты, включённый системный прокси;
    - история обнаружений за месяц.
- **Результат:**
  - **Оценка здоровья от 0 до 100** и вывод: «в хорошем состоянии», «есть что улучшить» или «нужно внимание». Видны дата проверки и её длительность.
  - **Проблемы по уровню опасности:** критично, высокий, средний, низкий, для сведения. У каждой проблемы есть цветная метка уровня и категория, заголовок с цифрами («На диске C осталось 18,2 ГБ»), блоки «Почему это важно» и «Как исправить» простым языком и при необходимости раскрывающиеся «Подробности» (имена угроз, программ, устройств, записей).
  - **Список «Проверено без проблем»** и проверки, которые не удалось выполнить (нет датчика или нужны права администратора).
- **Исправления:**
  - **Автоматические — кнопкой у проблемы.** Очистить мусор, включить сбалансированный план питания, обновить базы антивируса, удалить угрозы, запустить проверку, включить брандмауэр, включить UAC, включить службу обновлений, отключить подозрительную автозагрузку (без удаления), убрать подозрительные записи из hosts (копия файла сохраняется), отключить прокси, восстановить системные файлы Windows (DISM + SFC, 10–30 минут), проверить подозрительные файлы антивирусом.
  - **Ручные — кнопкой перехода.** Где автоматически исправлять небезопасно, кнопка ведёт в нужное место: процессы, автозагрузка, «Диск», очистка, «Защита», Диспетчер устройств, «Безопасность Windows», Центр обновлений, Планировщик заданий.
  - **«Исправить автоматически: N».** Выполняет все быстрые безопасные исправления разом. Сначала программа спрашивает подтверждение со списком исправлений и создаёт точку восстановления. Долгие исправления (восстановление файлов, проверки антивирусом) запускаются только по отдельности.
  - Исправленные проблемы помечаются «Исправлено». Если нужна перезагрузка, программа об этом пишет.
- **Сохранение:** последний отчёт сохраняется и показывается при следующем открытии раздела.
- **Без прав администратора** часть проверок пропускается, а исправления недоступны — программа об этом сообщает.

### 3. Очистка

Удаляет только мусор: временные файлы и кэши. Личные файлы, пароли, история и закладки браузеров не трогаются.

- **Сканирование:** запускается само при открытии раздела. Видно размер каждой категории и общий размер в центре анимированного кольца.
- **Категории.** У каждой есть галочка. Можно «Выбрать всё» или «Снять всё».
  - **Временные файлы** — папка Temp пользователя. Файлы моложе 2 часов не трогаются: их могут использовать запущенные установщики.
  - **Временные файлы Windows** — `Windows\Temp`, тоже с защитой 2 часа. Нужны права администратора.
  - **Кэш браузеров** — Chrome, Edge, Firefox, Яндекс.Браузер, Opera, Opera GX, Brave, Vivaldi, Chromium, все профили. Удаляется только кэш: Cache, Code Cache, GPUCache, кэш шейдеров.
  - **Миниатюры** — кэш превью картинок Проводника, создаётся заново.
  - **Дампы сбоев** — файлы памяти после вылетов программ и системы (CrashDumps, Minidump, MEMORY.DMP).
  - **Отчёты об ошибках** — Windows Error Reporting пользователя.
  - **Кэш шейдеров** — DirectX, NVIDIA, AMD, Intel. Создаётся заново при запуске игр.
  - **Файлы обновлений** — скачанные установщики обновлений Windows (`SoftwareDistribution\Download`). Файлы моложе суток не трогаются. Нужны права администратора.
  - **Оптимизация доставки** — кэш раздачи обновлений между ПК. Чистится штатной командой Windows. Нужны права администратора.
  - **Корзина** — очищается на всех дисках.
- **Очистка:** кнопка «Очистить N ГБ». Кольцо заполняется по мере готовности категорий, у каждой видна галочка или индикатор.
- **Итог:** сколько освобождено, сколько файлов удалено, сколько пропущено (заняты другими программами).
- **История:** очистки записываются, общий итог виден на главной.
- **Безопасность:** программа никогда не переходит по ярлыкам папок (junction и symlink). Перед каждой папкой она проверяет, что та не стала ссылкой наружу. Так никто не может подсунуть ссылку и заставить её удалить чужие или системные файлы.

### 4. Диск

Четыре вкладки.

- **Анализ.**
  - Карточки всех дисков: свободно, всего, тип SSD/HDD, полоса заполнения.
  - Нажатие на диск запускает быстрый параллельный обход всех папок. Видно счётчик файлов, объём, текущую папку и кнопку «Остановить».
  - Результат — список папок и файлов по убыванию размера, с полосой размера и процентом от родителя.
  - По папкам можно спускаться внутрь и возвращаться кнопкой «Вверх».
  - У каждой строки есть кнопки «Показать в проводнике» и «В корзину».
  - Можно выбрать любую папку для анализа.
- **Загрузки** — умный разбор папки «Загрузки» (переключатель позволяет так же разобрать «Рабочий стол»):
  - **Сводка:** сколько всего занимает папка, сколько можно удалить и сколько занимают старые файлы.
  - **Типы:** каждый файл и папка получают тип — установщики, архивы, образы дисков, видео, картинки, музыка, документы, торренты, недокачанные, папки, ярлыки, другое.
  - **Что можно удалить.** Программа сама помечает с объяснением:
    - **«Уже установлена: <программа>»** — установщики программ, которые уже есть на компьютере. Имя установщика сверяется со списком установленных программ и меню «Пуск».
    - **«Архив уже распакован рядом»** — архивы, рядом с которыми лежит папка с тем же именем.
    - **«Копия другого файла»** — точные дубликаты по содержимому. Самая старая копия считается оригиналом и не помечается.
    - **«Недокачанный файл»** — брошенные загрузки браузеров (.crdownload, .part и т. п.) старше суток.
    - **«Старше 90 дней»** — файлы, которые давно скачаны или не менялись.
  - **Фильтры:** «Можно удалить» (по умолчанию), «Всё», «Старые», плюс выбор типа.
  - **Список:** у каждого файла настоящая иконка, имя, тип, возраст, причина, размер и кнопка «Показать в проводнике».
  - **Удаление:** галочки, «Выбрать всё», кнопка «В корзину: N · размер». Удаляется только то, что видно на экране, и только в Корзину, с подтверждением и списком путей.
  - Разбор папки на 2–3 тысячи файлов занимает несколько секунд, результат запоминается при переключении вкладок.
- **Большие файлы** — 100 самых больших файлов (от 50 МБ) из последнего анализа. Можно показать в проводнике или отправить в корзину.
- **Дубликаты.**
  - Ищет одинаковые файлы больше 1 МБ в выбранной папке.
  - Сравнивает по содержимому в три шага: размер → хеш первых 64 КБ → хеш всего файла (BLAKE3).
  - Показывает группы и сколько можно освободить.
  - Кнопка «Оставить первый, остальные в корзину».
- **Удаление:** только в Корзину Windows, файлы можно вернуть. Перед удалением показывается список путей.
- **Защищённые пути:** системные пути удалить нельзя — Windows, Program Files, корни дисков, папки профиля пользователя, pagefile, hiberfil и т. п. Пути предварительно разворачиваются, поэтому обойти защиту через `..` или короткие имена не выйдет.
- Облачные файлы OneDrive, которых нет на диске, в размеры не считаются.

### 5. Программы

Все программы на компьютере, включая те, что не показывает панель управления.

- **Вкладки-фильтры:**
  - **Установленные** — классические программы из реестра.
  - **Microsoft Store** — приложения с ярлыком в меню «Пуск».
  - **Без установщика** — папки в Program Files без записи «установлено» в Windows, где лежит exe.
- **У каждой программы:**
  - настоящая иконка (а не буквы);
  - название, издатель, версия;
  - тип, дата установки, размер;
  - кнопка «Показать в проводнике»;
  - кнопка «Удалить».
- **Откуда берётся иконка** (по порядку): иконка из реестра, главный exe в папке программы, ярлык в меню «Пуск», кэш иконок установщика MSI, деинсталлятор. Если ничего не нашлось, ставится стандартный значок Windows.
- **Поиск и сортировка:** поиск по названию и издателю. Сортировка по имени, размеру или дате.
- **Удаление классических программ.**
  - Запускается их собственный деинсталлятор.
  - Программа ждёт, пока он закончит, и умеет ждать даже деинсталляторы, которые перезапускают себя из Temp.
  - Потом она ищет остатки — папку установки и папки в AppData и ProgramData с точным именем программы — и предлагает отправить их в Корзину.
  - Общие папки производителей (Microsoft, Intel, NVIDIA, Google и т. п.) никогда не предлагаются.
- **Удаление приложений Store** — штатной командой Windows.
- **Программы без установщика** — их папка отправляется в Корзину.
- **Системные компоненты** (WebView2, Visual C++, .NET, Edge и т. п.) помечены «Системная», и удалить их нельзя.

### 6. Система

Пять вкладок.

- **Обзор.**
  - Процессор (модель, ядра и потоки), видеокарты, объём памяти, версия и сборка Windows.
  - Имя компьютера, модель, время работы без перезагрузки.
  - Для ноутбуков: заряд и состояние батареи, износ (текущая ёмкость к заводской).
  - Быстрый запуск инструментов Windows: Диспетчер задач, Диспетчер устройств, Панель управления, Сведения о системе, Управление дисками, Службы.
- **Автозагрузка.**
  - Все программы, которые стартуют с Windows: реестр (пользователь и все пользователи, 32 и 64 бит) и папки автозагрузки.
  - У каждой иконка, команда, источник и переключатель вкл/выкл.
  - Отключение работает так же, как в Диспетчере задач: программа не удаляется, просто не запускается вместе с Windows.
- **Процессы.**
  - Список запущенных процессов с иконками, загрузкой процессора и памятью. Обновляется каждые 2,5 секунды.
  - Есть поиск и сортировка по имени, процессору или памяти.
  - Кнопка «Завершить» с подтверждением. Системные процессы (csrss, lsass, svchost, dwm и др.) завершить нельзя.
- **Службы.**
  - Все службы Windows с фильтром «Работающие / Все» и поиском.
  - Можно запустить, остановить или перезапустить службу и сменить тип запуска: автоматически, вручную, отключена.
  - Важные для Windows службы помечены и защищены от изменения.
- **Восстановление.**
  - Список точек восстановления и кнопка «Создать точку». Windows разрешает одну точку в сутки, и программа честно об этом говорит.
  - Включение защиты системы, если она выключена.
  - Кнопка «Открыть восстановление системы».

### 7. Защита

- **Microsoft Defender:**
  - защита в реальном времени (вкл/выкл);
  - дата обновления баз;
  - время последней проверки;
  - число активных угроз;
  - другой антивирус, если он установлен.
- **Кнопки Defender:**
  - «Открыть Безопасность Windows». Сам антивирус программа намеренно не выключает: это делается там, так надёжнее.
  - «Быстрая проверка» — проверка идёт в фоне, можно уходить на другие разделы.
  - «Обновить базы».
- **Брандмауэр:**
  - состояние для доменной, частной и общественной сети;
  - «Выключить» (с предупреждением) или «Включить везде»;
  - «Расширенные настройки».
- **Обновления Windows:** последние установленные обновления (KB-номер, тип, дата) и кнопка «Открыть Центр обновлений».

### 8. Сеть

Четыре вкладки.

- **Обзор.**
  - Сетевые адаптеры (Wi-Fi, Ethernet): статус, IP-адрес, шлюз, DNS, MAC, скорость канала.
  - Инструменты:
    - «Сбросить кэш DNS»;
    - смена DNS-сервера для всех активных подключений: автоматически (провайдер), Cloudflare 1.1.1.1, Google 8.8.8.8, Quad9 9.9.9.9, AdGuard (без рекламы);
    - «Сброс сети» (Winsock и TCP/IP, потом нужна перезагрузка).
- **Скорость.** Тест через серверы Cloudflare: пинг, загрузка (4 параллельных потока) и отдача. Живые значения видны во время теста, около 20 секунд.
- **Подключения.** Активные интернет-подключения: какая программа, локальный и удалённый адрес, состояние. Есть поиск.
- **Wi-Fi.** Сети, к которым подключался компьютер, их тип защиты и сохранённые пароли (показать, скрыть, скопировать). Пароли читаются через системный API Windows прямо в памяти, без записи на диск.

### 9. Игры

- **Игровой режим одной кнопкой.** Перед включением можно отметить, что именно сделать:
  - план питания «Высокая производительность». Если он скрыт, как на многих ноутбуках, создаётся копия, а при выключении удаляется;
  - игровой режим Windows;
  - отключение прозрачности и анимаций Windows;
  - пауза обновлений Windows на сутки;
  - закрытие выбранных фоновых программ. Тяжёлые программы — браузеры, Discord, Telegram, OneDrive, Spotify и др. — показываются списком с памятью, по умолчанию ничего не отмечено.
- **Полный откат.** Кнопка «Выключить и вернуть как было» возвращает все прежние значения, в том числе удаляет настройки, которых раньше не было. Прежние значения сохраняются до каждого изменения, поэтому откат работает даже после сбоя или перезагрузки.
- **Подсказка для ноутбуков:** подключить зарядку, иначе видеокарта работает слабее.
- **Честное ожидание:** обычно +5–15% FPS и меньше подтормаживаний, без «магических ускорителей».
- **Видеокарта для игр.** Добавляешь exe игры и назначаешь ей мощную видеокарту (полезно для ноутбуков с двумя), энергосбережение или «авто». Можно менять и удалять.

### 10. Настройки

- **Язык:** русский или английский.
- **Запуск вместе с Windows.** Через Планировщик заданий, сразу с правами администратора и без окна UAC. Работает и от батареи.
- **Запускать свёрнутой** — при автозапуске сразу в трей.
- **Сворачивать в трей при закрытии.**
- **Нагрузка в трее** — процессор и память в подсказке у значка.
- **Горячая клавиша:** выключена, `Ctrl+Shift+Space`, `Ctrl+Alt+S` или `Alt+Shift+S`.
- **Анимации:** полные, меньше, выключены.
- **Папка программы и папка данных** — открыть в проводнике.
- **О программе:** версия и сборка Windows.
- **«Проверить обновления».** Всегда пишет результат строкой: «Обновлений нет — у вас последняя версия X», «Есть новая версия StepMaster» с кнопкой «Обновить», или текст ошибки.

## Обновления

- **Проверка:** при каждом запуске программа сама смотрит последний релиз на GitHub (`c1naii/StepMaster`).
- **Окно:** если вышла новая версия, по центру появляется окно в стиле программы «Нужно обновить программу» с кнопками «Обновить» и «Позже». Номер версии не показывается.
- **Установка:** по «Обновить» новая версия скачивается с полосой прогресса.
  - Программа проверяет цифровую подпись файла (minisign, Ed25519) — подделку она не установит.
  - Потом заменяет свой файл на месте (имя не меняется) и перезапускается сама. Версия в списке приложений Windows обновляется.
  - Всё внутри программы, без стандартных окон установщика Windows.
- **Без интернета** проверка тихо пропускается.

## Где что хранится

- **Программа** — в папке установки (по умолчанию `C:\Program Files\StepMaster\StepMaster.exe`).
- **Запись в списке приложений** — `HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Uninstall\StepMaster`.
- **Ярлыки** — `C:\ProgramData\Microsoft\Windows\Start Menu\Programs\StepMaster.lnk` и `StepMaster.lnk` на рабочем столе.
- **Настройки и история очисток** — `%LOCALAPPDATA%\com.stepmaster.app\`:
  - `settings.json` — настройки;
  - `history.json` — история очисток;
  - `game-mode.json` — сохранённые значения для отката игрового режима;
  - `diagnostics.json` — последний отчёт умной диагностики;
  - `hosts.backup-<время>` — копия файла hosts перед автоматическим исправлением.
- **Автозапуск** — задание «StepMaster» в Планировщике заданий Windows.

## Безопасность и надёжность

- Пользовательские файлы удаляются только в Корзину, с подтверждением и списком путей.
- Очистка работает только с фиксированным списком папок кэша и временных файлов.
- Системные пути, системные процессы, важные службы и системные компоненты защищены от удаления и изменения.
- Все изменения системы обратимы: игровой режим откатывается, автозагрузка переключается обратно, точки восстановления создаются из программы.
- Системные утилиты (PowerShell, netsh, ipconfig, powercfg, msiexec, explorer) вызываются только по полным путям из System32, а не по имени. Программу нельзя обмануть подложенным рядом файлом.
- Обновления принимаются только с правильной цифровой подписью.
- Перед выпуском программа проверялась:
  - 44 автоматических теста логики на Rust (в том числе правила диагностики, сопоставления установщиков и выбора папки установки);
  - 10 тестов интерфейса;
  - проверка на реальной системе;
  - ревью кода, аудит безопасности, отдельное ревью диагностики и тест интерфейса в худших условиях (длинные имена, пустые списки, ошибки).
- Диагностика осторожна:
  - нежелательные программы (PUA, «кряки») не удаляются автоматически, потому что часто установлены сознательно;
  - локальный прокси VPN-клиента (127.0.0.1) не считается проблемой;
  - если сбор данных не удался, проверка помечается «не удалось проверить», а не выдаёт ложную тревогу;
  - «Исправить всё» выполняет только безопасные быстрые действия, остальное требует отдельного подтверждения со списком.

## Устройство (для разработчиков)

- **Интерфейс:** React 19 + TypeScript + Vite, анимации Motion, иконки Lucide.
- **Системная часть:** Rust + Tauri 2. Реестр, WinAPI, WMI/PowerShell, WLAN API, извлечение иконок из exe.
- **Модули:** каждый раздел — отдельный модуль. Новые функции добавляются в нужный раздел, не трогая остальные.
- **Сборка:** `npm run release` собирает и подписывает `StepMaster.exe`. Выпуск обновления: `scripts/release.ps1 -Version X.Y.Z -Publish`.

## Ограничения

- **SmartScreen.** Программа не подписана платным сертификатом Microsoft, поэтому при первом скачивании Windows может показать «Неизвестный издатель». Нужно нажать «Подробнее» → «Выполнить в любом случае».
- **Права администратора.** Без них часть функций недоступна: системная очистка, службы, брандмауэр, DNS, игровой режим, удаление программ, пароли Wi-Fi.
- **Системы:** Windows 7 и 8 не поддерживаются.
