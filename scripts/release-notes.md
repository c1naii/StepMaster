## Новое
- Менеджер программ winget ставится сам — вкладка «Установить» работает сразу, без Microsoft Store
- Исправления из диагностики можно вернуть в «Журнале»: питание, брандмауэр, обновления Windows, прокси, автозагрузка
- Кнопка «Остановить» у восстановления файлов Windows
- Окно «Что нового» после обновления

## Исправлено
- На флешке и сетевом диске файлы больше не удаляются насовсем вместо Корзины
- Диагностика замечает полностью забитый диск C:
- Иконка только что установленной программы появляется сразу
- Игровой режим не теряет прежние настройки при двойном клике
- Программа больше не может зависнуть навсегда на системных командах
- Быстрые переключения в настройках и автозагрузке больше не сбивают выбор

---

StepMaster для Windows 10 и 11.

Скачай `StepMaster.exe` и запусти. Windows попросит права администратора.
Если появится «Неизвестный издатель» (SmartScreen), нажми «Подробнее» → «Выполнить в любом случае».

Программа сама проверяет эту страницу и предлагает обновиться. Файл `StepMaster.exe.sig` — подпись обновления, для запуска он не нужен.
